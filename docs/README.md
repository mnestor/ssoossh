# ssoossh documentation

**ssoossh** (pronounced *sue-sssh*) is SSO for SSH: users authenticate via OIDC
and receive short-lived SSH certificates instead of managing long-lived keys.
Self-hosted, homelab-friendly, early development.

## A note on retired plans

Earlier revisions of this index treated a `release-plan.md` and seven
`release-phase*.md` files as the current plan. Those documents were retired
and are not in the repo; the dead references to them were stripped from every
citing document on 2026-08-22. The "Planned" and "Designed but deferred"
tables above are the source of truth for what is in and out of scope.

A `security-review-2026-08-11.md` was likewise cited but never present; that
reference is gone too, superseded by the work now consolidated into the three
files above. The three source reviews they were consolidated from
(`security-and-api-audit-2026-08-21.md`, `feature-review-2026-08-22.md`,
`comparative-audit-2026-08-22.md`) were removed in the same pass — their
findings, their "already solid" conclusions, and their explicit
not-applicable lists all live in the three files above.
