This installs ssoossh @VERSION@, the command-line client for an ssoosshd server. It exchanges a browser sign-in for a short-lived SSH certificate, so you log in to hosts without a key on disk that outlives the session.

It installs only files, all under /usr/local. Nothing runs in the background, no login item is added, and your SSH configuration is not touched -- the next pane says what to add and where.

Built for @ARCHNAME@ (@HOSTARCH@), macOS @MINVER@ or later. The binary is signed with a Developer ID certificate and notarized by Apple.
